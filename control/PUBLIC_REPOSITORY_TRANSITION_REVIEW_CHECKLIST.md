# Public repository transition — review checklist

- [ ] Code/configuration licence is Apache-2.0.
- [ ] Original editorial content licence is CC-BY-4.0.
- [ ] Third-party material is linked and attributed, not relicensed or bundled.
- [ ] Trademark/brand boundary is explicit.
- [ ] Application logs exclude request and response content.
- [ ] Hosting metadata handling and retention are documented accurately.
- [ ] Public MCP remains read-only by route, schema, application and test.
- [ ] No credentials, private endpoints or live-network actions are committed.
- [ ] The public endpoint is documented as a read-only technical preview.
