# SORA For Agents MCP Worker

This Worker turns the checked-in `../corpus/review-corpus.json` into a stateless
Streamable HTTP MCP service at `/mcp`. It contains no credentials, network
fetches, logging of query bodies, wallet operations, signatures, payments,
swaps, staking, deployment tools or write operations.

## Scope

- Five read-only tools: `search_content`, `get_topic`, `list_links`,
  `list_ecosystem_access`, `get_playlist_catalog`.
- One read-only resource: `sora://tridente/review-corpus`.
- Health endpoint: `GET /health`.
- Request size: 32 KB maximum.
- Rate limit: 10 requests per minute for each client IP at the Cloudflare edge.
- The bundled corpus is generated by `scripts/sync-corpus.mjs`; never edit
  `src/corpus.generated.json` directly.

## Local validation

```bash
npm install
npm run check
```

For an optional local Worker runtime, install the current Wrangler CLI,
copy `wrangler.example.jsonc` to local `wrangler.jsonc`, replace its
placeholders, and run `wrangler dev`. Connect a Streamable HTTP MCP client to
the local `/mcp` URL Wrangler prints. A browser cannot validate MCP directly.

## Deployment gate

This repository intentionally contains no live account, route, hostname or
rate-limit namespace configuration. Copy `wrangler.example.jsonc` to a local,
ignored `wrangler.jsonc`, replace every placeholder, then run a local and a
remote MCP-client test before deploying your own instance.
