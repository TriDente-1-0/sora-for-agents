# SORA For Agents MCP

This package turns the checked-in `../corpus/review-corpus.json` into a stateless
Streamable HTTP MCP service at `/mcp`. It contains no credentials, network
fetches, logging of query bodies, wallet operations, signatures, payments,
swaps, staking, deployment tools or write operations.

## Scope

- Seven read-only tools: `search_content`, `get_topic`, `get_document`,
  `list_atlas_diagrams`, `list_links`, `list_ecosystem_access`, and
  `get_playlist_catalog`.
- One read-only resource: `https://github.com/TriDente-1-0/sora-for-agents/blob/main/corpus/review-corpus.json`.
- Health endpoint: `GET /health`.
- Request size: 32 KB maximum.
- The bundled corpus is generated by `scripts/sync-corpus.mjs`; never edit
  `src/corpus.generated.json` directly.
- Versioned document representations: `../corpus/whitepaper.json` and
  `../corpus/case-for-xor.json`. The Makoto article remains in the general
  document index only.
