# Contributing

Thank you for improving this read-only knowledge service. Use a branch and a
pull request; do not push directly to `main`.

Before opening a pull request, state the source of truth, evidence status,
data boundary and tests run. Keep third-party material linked and attributed;
do not add copied page text, screenshots, videos, credentials, private
endpoints or personal data. Original code and configuration are Apache-2.0;
original editorial records follow `CONTENT_LICENSE.md`.

Report vulnerabilities through the private route in `SECURITY.md`, never in a
public issue. The maintainers may decline material that lacks provenance,
exceeds the read-only scope, or conflicts with the repository policies.
