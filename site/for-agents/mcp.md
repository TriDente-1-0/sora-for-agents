# SORA Nexus — MCP

The site and read-only Streamable HTTP MCP service are deployed together. The
MCP endpoint is [`/mcp`](/mcp) on the same origin. Its source is
[`../../mcp-worker`](../../mcp-worker). It has seven read-only tools and one
corpus resource; it has no credentials, wallet, signing, transaction,
remote-browsing or write capability.
